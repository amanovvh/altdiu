# 🚨 Экстренный гайд: что делать если сайт упал

> **Для кого:** любой, у кого есть доступ к Vercel. Не нужны навыки программирования.

---

## 🔥 Сначала — не паникуй

Vercel делает **автоматический бэкап** каждого деплоя. Если что-то сломалось, откатить можно за 30 секунд одной кнопкой. Данные пользователей и админки **не потеряются**.

---

## 🚨 Три самых частых сценария

### 1. Сайт показывает ошибку 500 / белую страницу

**Причина:** скорее всего, последний деплой сломался.

**Что делать:**

1. Открой https://vercel.com/hasan-4f99/altdiu/deployments
2. Найди **последний успешный** деплой (зелёная иконка ✅)
3. Нажми на него → **⋮** → **Promote to Production**
4. Подожди 30 секунд. Сайт должен заработать.

Если не помогло — переходи к разделу «Что-то посерьёзнее».

---

### 2. Сайт вообще не открывается (502, DNS, таймаут)

**Причина:** возможно Vercel упал, или домен не настроен.

**Что делать:**

1. Открой https://www.vercel-status.com — посмотри, не упал ли Vercel
2. Если Vercel работает, а сайт нет:
   - Зайди в Vercel Dashboard → Deployments
   - Если последний деплой «Error» — нажми **Redeploy** на последнем успешном
4. Если домен `financelyceum.uz` не открывается, а `altdiu.vercel.app` работает:
   - Домен не привязан / истёк / DNS сломан
   - Проверь https://dnschecker.org/#A/financelyceum.uz
   - Если истёк — продли у регистратора (cctld.uz)

---

### 3. Админка не пускает (забыли пароль)

**Что делать:**

Если есть доступ к Prisma (https://console.prisma.io):
1. Открой таблицу `User`
2. Найди себя → удали строку → создай новую командой:
   ```bash
   npx tsx scripts/create-admin.ts --email your@email.com --password "НовыйПароль123" --name "Имя" --role SUPER_ADMIN
   ```

Если нет доступа к Prisma:
- Напиши бывшему разработчику (см. CONTACTS.md)
- Или найми фрилансера на час работы

---

## 🛠 Что-то посерьёзнее (build failed, БД недоступна)

### Откатить последний деплой

1. Vercel → Deployments
2. Найди последний **Ready** (зелёный)
3. **⋮** → **Promote to Production**
4. Подожди 30 сек → проверь сайт

### Если Vercel показывает ошибку в логах

1. Кликни на Failed деплой → **Building** → найди красную строку
2. Если ошибка про `Cannot find name 'X'` или TypeScript — нужен разработчик
3. Если ошибка про БД (Postgres connection failed) — проверь Prisma Dashboard

### База данных недоступна

1. Открой https://console.prisma.io
2. Если Prisma показывает «Database is suspended» — возможно превышен free tier (маловероятно)
3. **Включи** её обратно через Prisma Dashboard

## 🎯 Универсальный план за 5 минут

1. **Сайт не открывается?** Открой https://www.vercel-status.com
2. **Vercel работает?** Зайди в Vercel Dashboard → Deployments → найди последний Ready → **Promote to Production**
3. **Не помогло?** Открой последний Failed деплой → пришли скриншот логов разработчику
4. **Разработчик недоступен?** Найми фрилансера: 1-2 часа работы = $30-60

**В 99% случаев шаги 1-2 решают проблему за 1 минуту.**

---

> 💡 **Помни:** Vercel, Prisma, GitHub — это managed сервисы мирового уровня. Они работают с uptime 99.9%. Если сайт упал — скорее всего, это последний деплой. Откати его и живи спокойно.
