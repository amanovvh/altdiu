# 📋 Руководство администратора сайта

> **Для кого:** контент-менеджер / преемник, который будет обновлять сайт после окончания учебы текущим разработчиком.

Это **единственная инструкция, которая нужна для повседневной работы** — публикация новостей, фото в галерею, обновление текстов. Без программирования.

---

## 🚀 Быстрый старт (5 минут)

1. Открой https://altdiu.vercel.app/admin
2. Введи логин и пароль (получи у директора / IT-отдела)
3. Ты в панели управления. Слева — меню разделов.

**Меню слева:**

| Раздел | Что внутри |
|---|---|
| 📊 **Дашборд** | Главная страница — статистика, последние новости |
| 📰 **Новости** | Список всех новостей, можно добавлять/редактировать/удалять |
| 🏆 **Достижения** | Олимпиады, награды, победы |
| 👨‍🏫 **Преподаватели** | Список учителей с фото и био |
| 🏛 **Администрация** | Директор, завучи |
| 📚 **Направления** | Программы обучения (экономика, языки) |
| 🖼 **Галерея** | Фотоальбомы событий |
| 📞 **Контакты** | Адрес, телефоны, соцсети (по языкам) |
| 🏫 **О лицее** | Тексты про историю, миссию |
| 👥 **Пользователи** | Управление админами (только для SUPER_ADMIN) |
| ⚙️ **Настройки** | Смена своего пароля, статистика hero |

## 📰 Как добавить новость

1. Слева **Новости** → кнопка **+ Добавить**
2. Заполни:
   - **Заголовок** — на русском, узбекском, английском
   - **Slug** — URL-friendly (например `olimpiada-po-matematike-2026`). Обычно формируется автоматически.
   - **Текст** — на трёх языках. Если нет перевода — поле можно оставить пустым, на сайте покажется только русский.
   - **Обложка** — основное фото
   - **Дополнительные фото** — для галереи внутри новости
   - **Категория** — Объявление / Мероприятие / Достижение / Другое
   - **Закрепить на главной** — поставь галку чтобы показывать на главной странице
3. **Статус:** выбери **Опубликовано** (иначе новость не появится на сайте)
4. Нажми **Сохранить**
5. Проверь на сайте: https://altdiu.vercel.app/ru/news — она должна появиться через 10 секунд

---

## 🖼 Как загрузить фото в галерею

1. Слева **Галерея** → **+ Новый альбом**
2. Заполни:
   - **Название** альбома (на 3 языках)
   - **Slug** — URL (например `den-otkrytyh-dverey-2026`)
   - **Обложка** — главное фото альбома (показывается в списке)
   - **Фотографии** — все фото альбома. Можно загружать по одному или несколько сразу
   - **Дата** — когда прошло событие
3. Нажми **Сохранить**

Фото хранятся в облаке (Vercel Blob), оптимизируются автоматически.

## 🏆 Как добавить достижение

1. **Достижения** → **+ Добавить**
2. Заполни:
   - **Категория:** Олимпиада / Сертификат / Конкурс / Спорт / Другое
   - **Заголовок** (на 3 языках)
   - **Описание**
   - **Дата**
   - **Фото** — основное + дополнительные
3. **Сохранить**

---

## 👨‍🏫 Как добавить преподавателя

1. **Преподаватели** → **+ Добавить**
2. Заполни:
   - **ФИО**
   - **Категория** — экономика, языки, математика, и т.д.
   - **Предмет**
   - **Должность**
   - **Образование**
   - **Фото** — портрет
   - **Би**о (опционально)
3. **Сохранить**

**Контакты** → выбери язык (ru/uz/en) → отредактируй:
- Адрес
- Телефон
- Email
- Соцсети (Telegram, Instagram, YouTube, и т.д.)

## 🏫 Как обновить текст «О лицее»

**О лицее** → секции:
- **История**
- **Общая информация**
- **Миссия и задачи**
- **Особенности обучения**
- **Преимущества**
- **Образовательная среда**

Каждая секция имеет текст на 3 языках. Можно использовать **HTML** для форматирования (жирный, списки, ссылки).

1. В шапке сайта (где логотип лицея) нужно большое фоновое фото
2. Чтобы его заменить — это делается **через базу данных**, не из админки
3. Подробная инструкция для программиста: см. README → раздел «Hero photo»

> ⚠️ Если ты не программист — попроси IT-отдел или разработчика. Это разовая задача.

## 👥 Как добавить ещё одного админа (для будущего преемника)

1. Зайди в админку с правами **SUPER_ADMIN**
2. **Пользователи** → **+ Добавить**
3. Заполни: email, имя, пароль, роль
4. Доступные роли:
   - **SUPER_ADMIN** — может всё, включая управление другими админами
   - **ADMIN** — может всё кроме управления админами
   - **EDITOR** — может только создавать/редактировать контент, не может удалять

> 💡 Когда ты уйдёшь — добавь преемника как ADMIN, и он сможет продолжить работу без тебя.

## 🔑 Как сбросить пароль если забыл

Через БД:
1. Зайди в https://console.prisma.io (логин/пароль от Prisma)
2. Найди таблицу `User` → найди себя → измени поле `passwordHash`
3. Хеш пароля можно сгенерировать командой:
   ```bash
   npx tsx scripts/create-admin.ts --email your@email.com --password "новый_пароль" --name "Твоё Имя" --role ADMIN
   ```
   Это обновит пароль (или создаст нового админа если тебя нет).

## ⚠️ Чего НЕ делать

- ❌ Не удаляй чужие новости/альбомы без подтверждения директора
- ❌ Не публикуй личные данные студентов (телефоны, адреса)
- ❌ Не загружай фото больше 5 MB (это замедляет сайт)
- ❌ Не меняй код — для этого есть IT-отдел
- ❌ Не отключай сайт на технические работы без предупреждения директора

## 🆘 Если что-то сломалось

| Симптом | Что проверить |
|---|---|
| Не пускает в админку | Проверь пароль, попробуй сбросить через `create-admin.ts` |
| Новость не появляется на сайте | Проверь статус — должно быть «Опубликовано», а не «Черновик» |
| Фото не загружается | Подожди 1 минуту и попробуй снова. Если не помогло — размер файла больше 5 MB или формат не jpg/png |
| Сайт полностью не открывается | См. **EMERGENCY.md** |
| Нужно поменять что-то в коде | Обратись к IT-отделу / найми фрилансера на 2-3 часа |
